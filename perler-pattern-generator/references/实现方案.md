# 拼豆图纸生成器 - 技术实现方案

## 一、项目概述

### 1.1 目标
将任意图片转换为拼豆图纸，支持：
- 多种**色号标准**（MARD/Perler/Hama/Artkal/Nabbi/Yant/IKEA等）
- 多种板子尺寸（29x29、50x50、自定义）
- 批量处理
- 纯前端实现，无需服务器

### 1.2 色号标准体系

本工具支持以下主流拼豆品牌的色号标准：

| 品牌标准 | 颜色数 | 产地 | 特点 | 适用场景 |

## 三、核心算法设计

### 3.1 像素化算法

**目标：** 将任意尺寸图片缩放到指定像素数（如 29x29）

**算法：**
```javascript
function pixelate(image, targetWidth, targetHeight) {
  // 1. 创建临时 canvas
  const canvas = document.createElement('canvas');
  canvas.width = targetWidth;
  canvas.height = targetHeight;
  const ctx = canvas.getContext('2d');
  
  // 2. 关闭平滑，使用最近邻插值（保持像素风格）
  ctx.imageSmoothingEnabled = false;
  
  // 3. 缩放绘制
  ctx.drawImage(image, 0, 0, targetWidth, targetHeight);
  
  // 4. 提取像素数据
  return ctx.getImageData(0, 0, targetWidth, targetHeight);
}
```

**关键点：**
- `imageSmoothingEnabled = false` 保证像素清晰锐利
- 支持自定义宽高（非正方形）
- 可选：智能裁剪，保留图片主体区域

### 3.2 颜色匹配算法（核心）

**为什么用 CIE-Lab？**
- RGB 是设备相关的色彩空间，颜色数值差异 ≠ 视觉差异
- CIE-Lab 是设备无关的色彩空间，模拟人眼感知
- Lab 空间中两点距离（ΔE）直接反映视觉色差

**算法流程：**

```
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│ RGB像素  │ ──▶ │ XYZ转换  │ ──▶ │ Lab转换  │ ──▶ │ 遍历色卡 │
└──────────┘     └──────────┘     └──────────┘     └──────────┘
                                                        │
                                                        ▼
                                                ┌──────────┐
                                                │ 计算ΔE  │
                                                └──────────┘
                                                        │
                                                        ▼
                                                ┌──────────┐
                                                │ 返回最匹配│
                                                └──────────┘
```

**代码实现：**

```javascript
// RGB → XYZ 转换
function rgbToXyz(r, g, b) {
  // 归一化到 0-1
  r = r / 255;
  g = g / 255;
  b = b / 255;
  
  // Gamma 校正
  r = r > 0.04045 ? Math.pow((r + 0.055) / 1.055, 2.4) : r / 12.92;
  g = g > 0.04045 ? Math.pow((g + 0.055) / 1.055, 2.4) : g / 12.92;
  b = b > 0.04045 ? Math.pow((b + 0.055) / 1.055, 2.4) : b / 12.92;
  
  // RGB → XYZ 矩阵变换（sRGB D65）
  const x = (r * 0.4124564 + g * 0.3575761 + b * 0.1804375) * 100;
  const y = (r * 0.2126729 + g * 0.7151522 + b * 0.0721750) * 100;
  const z = (r * 0.0193339 + g * 0.1191920 + b * 0.9503041) * 100;
  
  return { x, y, z };
}

// XYZ → Lab 转换
function xyzToLab(x, y, z) {
  // D65 白点参考值
  const xn = 95.047, yn = 100.000, zn = 108.883;
  
  // 归一化并应用 f 函数
  const fx = f(x / xn);
  const fy = f(y / yn);
  const fz = f(z / zn);
  
  const L = 116 * fy - 16;
  const a = 500 * (fx - fy);
  const b = 200 * (fy - fz);
  
  return { L, a, b };
}

function f(t) {
  const delta = 6 / 29;
  return t > delta ? Math.pow(t, 1/3) : t / (3 * delta * delta) + 4 / 29;
}

// RGB → Lab 一键转换
function rgbToLab(r, g, b) {
  const xyz = rgbToXyz(r, g, b);
  return xyzToLab(xyz.x, xyz.y, xyz.z);
}

// 计算 ΔE (CIE76 简化版，够用)
function deltaE(lab1, lab2) {
  return Math.sqrt(
    Math.pow(lab1.L - lab2.L, 2) +
    Math.pow(lab1.a - lab2.a, 2) +
    Math.pow(lab1.b - lab2.b, 2)
  );
}

// 找到最匹配的拼豆颜色
function findClosestBeadColor(rgb, palette) {
  const pixelLab = rgbToLab(rgb.r, rgb.g, rgb.b);
  
  let minDelta = Infinity;
  let closestColor = null;
  
  for (const bead of palette) {
    const beadLab = rgbToLab(bead.r, bead.g, bead.b);
    const delta = deltaE(pixelLab, beadLab);
    
    if (delta < minDelta) {
      minDelta = delta;
      closestColor = bead;
    }
  }
  
  return { color: closestColor, delta: minDelta };
}
```

**性能优化：**
- 预计算所有色卡颜色的 Lab 值，存储在 JSON 中
- 匹配时直接使用预计算的 Lab 值，省去转换开销
- 批量处理时使用 Web Worker 避免阻塞 UI

### 3.3 网格图纸生成算法

**目标：** 生成带网格线、颜色标注、材料清单的图纸

**输出结构：**
```
┌────────────────────────────────────┐
│                                    │
│        [像素网格图 + 网格线]        │
│        [每个格子标注色号]          │
│                                    │
├────────────────────────────────────┤
│  材料清单：                         │
│  ● H1 白色 x 156颗                 │
│  ● H7 黑色 x 89颗                  │
│  ● A4 黄色 x 45颗                  │
│  ...                               │
│                                    │
│  总计：29x29 = 841颗               │
│  使用颜色：12种                     │
└────────────────────────────────────┘
```

**代码实现：**

```javascript
function generatePatternGrid(pixelData, colorMap, options = {}) {
  const { 
    gridSize = 29, 
    cellSize = 20,           // 每个格子的像素大小
    showGridLines = true,
    showColorCode = true,
    fontSize = 8
  } = options;
  
  const canvas = document.createElement('canvas');
  const width = gridSize * cellSize;
  const height = gridSize * cellSize;
  canvas.width = width;
  canvas.height = height;
  
  const ctx = canvas.getContext('2d');
  
  // 统计颜色数量
  const colorCount = {};
  
  // 绘制每个格子
  for (let y = 0; y < gridSize; y++) {
    for (let x = 0; x < gridSize; x++) {
      const idx = (y * gridSize + x) * 4;
      const r = pixelData.data[idx];
      const g = pixelData.data[idx + 1];
      const b = pixelData.data[idx + 2];
      
      // 找到匹配的拼豆颜色
      const matched = colorMap[y * gridSize + x];
      
      // 绘制格子背景色
      ctx.fillStyle = `rgb(${matched.r}, ${matched.g}, ${matched.b})`;
      ctx.fillRect(x * cellSize, y * cellSize, cellSize, cellSize);
      
      // 绘制网格线
      if (showGridLines) {
        ctx.strokeStyle = '#ccc';
        ctx.lineWidth = 0.5;
        ctx.strokeRect(x * cellSize, y * cellSize, cellSize, cellSize);
      }
      
      // 标注色号
      if (showColorCode && cellSize >= 15) {
        ctx.fillStyle = getContrastColor(matched);
        ctx.font = `${fontSize}px Arial`;
        ctx.textAlign = 'center';
        ctx.textBaseline = 'middle';
        ctx.fillText(matched.code, x * cellSize + cellSize/2, y * cellSize + cellSize/2);
      }
      
      // 统计
      colorCount[matched.code] = (colorCount[matched.code] || 0) + 1;
    }
  }
  
  return { canvas, colorCount };
}

// 根据背景色选择对比文字颜色
function getContrastColor(color) {
  const luminance = (0.299 * color.r + 0.587 * color.g + 0.114 * color.b) / 255;
  return luminance > 0.5 ? '#000' : '#fff';
}
```

### 3.4 批量处理算法

**策略：**
- 使用队列管理多个图片任务
- 每个图片独立处理，互不干扰
- 支持进度显示和取消操作

```javascript
class BatchProcessor {
  constructor(options) {
    this.queue = [];
    this.results = [];
    this.currentIndex = 0;
    this.options = options;
    this.isRunning = false;
  }
  
  addFiles(files) {
    this.queue.push(...files);
  }
  
  async processAll() {
    this.isRunning = true;
    
    while (this.currentIndex < this.queue.length && this.isRunning) {
      const file = this.queue[this.currentIndex];
      const result = await this.processOne(file);
      this.results.push(result);
      this.currentIndex++;
      
      // 回调进度
      this.options.onProgress?.({
        current: this.currentIndex,
        total: this.queue.length,
        result
      });
    }
    
    return this.results;
  }
  
  stop() {
    this.isRunning = false;
  }
}
```

## 六、性能优化策略

### 6.1 颜色匹配优化

| 优化项 | 方法 | 效果 |
|--------|------|------|
| 预计算 Lab | 色卡 JSON 预存 Lab 值 | 省去转换时间 |
| KD-Tree 加速 | 构建 Lab 空间 KD-Tree | O(n) → O(log n) |
| 缓存结果 | 相同颜色缓存匹配结果 | 避免重复计算 |

### 6.2 大图处理优化

| 场景 | 优化方法 |
|------|---------|
| 大尺寸图片 | 先缩放到合理尺寸再处理 |
| 批量处理 | 使用 Web Worker 后台处理 |
| UI 阻塞 | 分片处理 + requestAnimationFrame |

### 6.3 内存优化

- 使用 TypedArray 存储像素数据
- 及时释放 Canvas 引用
- 批量处理时逐个处理，不一次性加载所有图片

| 分板拼接 | 大图自动拆分为多个小板 | 高 |

## 九、风险与应对

| 风险 | 应对策略 |
|------|---------|
| 大图性能问题 | 限制最大尺寸 + Web Worker |
| 色差过大 | 提供"调整颜色"功能手动干预 |
| 浏览器兼容 | 使用标准 API，提供降级方案 |
| 移动端体验 | 响应式设计 + 触摸优化 |
